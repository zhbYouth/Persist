# 日恒 Android v1.2（含桌面小组件）

可用 Android Studio 打开的原生 Android 项目。主界面运行日恒的网页应用（`app/src/main/assets/index.html`），
原生桌面小组件直接读取共享数据，可在桌面查看今日计划并点按打卡。

## v1.2 更新（相对 v1.1）
- **备份真正可用**：设置里的「导出」改为调用系统的「保存到」选择器；新增「导入备份」，导入前会先确认，且会校验文件格式。
  （v1.1 里导出按钮在 App 内点了没有任何文件，却会提示“已导出”。）
- **固定签名**：`app/riheng.jks`。以后每次构建（包括 GitHub Actions）的 APK 都用同一把 key，**可以直接覆盖安装**，不再需要卸载重装、打卡数据不会丢。
- **小组件**：按布局实际高度精确计算行数，不再裁切；放不下的习惯显示「还有 N 项」；打卡按钮改为圆形、点击区更大；配色与应用一致，并跟随系统深色模式；跨天 / 改时间 / 改时区时自动刷新。
- **返回键**：先关弹窗，再从统计/设置回到「今日」，都不需要时才退出。
- **软键盘**：弹出时页面上移，不再遮挡「新习惯」输入框。
- **点小组件回到应用**时复用已有窗口，不再重新加载页面；应用在后台时会暂停网页，省电。
- 屏幕常亮跨过零点时，应用内会自动切换到新的一天。

## ⚠️ 第一次安装 v1.2 需要先卸载旧版
旧版本是用 GitHub Actions 临时生成的签名构建的，和 v1.2 的固定签名不同，系统不允许覆盖安装。
**只有这一次**需要先卸载再装（旧版的数据会随之清除；旧版导出功能本来就不可用，没有办法在卸载前导出）。
从 v1.2 起，后续版本都可直接覆盖安装。

> `app/riheng.jks` 是个人自用的固定签名文件，密码写在 `app/build.gradle.kts` 里，用于保证覆盖安装。
> 它不适合用于上架应用商店；如果仓库是公开的，也不要用它签名任何需要保密的应用。

## 小组件功能
- 显示今天已完成数量和计划习惯，按桌面分配的高度显示若干行
- 点右侧圆圈直接打卡 / 取消打卡
- 点习惯名称或“打开日恒”进入应用
- 小组件打卡与应用数据通过原生 SharedPreferences 同步
- 支持从桌面添加、调整大小

## 构建 APK
- **GitHub Actions**：推送到 main/master 会自动构建，完成后在 Actions → 对应运行 → Artifacts 下载 `riheng-debug-apk`（解压得到 `app-debug.apk`）；也可手动运行 workflow。
- **Android Studio**：打开项目根目录，安装 Android SDK Platform 35 和 JDK 17，Build > Build APK(s)，产物在 `app/build/outputs/apk/debug/app-debug.apk`。

## 测试桌面小组件
安装后长按桌面空白处 → 小组件 → 搜索“日恒” → 添加“日恒打卡小组件”。不同桌面的操作名称可能略有差异。

## 数据与限制
- 习惯和打卡记录保存在应用内（WebView 本地存储 + 原生 SharedPreferences 副本，后者供小组件使用）。**卸载应用会清除数据**，请定期在设置里导出备份。
- 自定义图片图标在应用内可用；小组件里暂时显示为 🌿，预设图标显示对应 Emoji。
- 当前版本不含云同步、账号系统或通知提醒。
- 设置里的主题选择在 v1.1 已移除，固定为默认主题。

验证范围与已知限制见 [BUG_AUDIT.md](BUG_AUDIT.md)。
