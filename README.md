# Persist Android v1.6（含桌面小组件）

原名「日恒」。可用 Android Studio 打开的原生 Android 项目：主界面运行网页应用（`app/src/main/assets/index.html`），
原生桌面小组件直接读取共享数据，可在桌面查看今日计划并点按打卡。

## 下载安装
推送到 main 后 GitHub Actions 会自动构建，并发布成 **Release**：打开仓库的 **Releases** 页，点最新一条里的 `Persist-x.y.z.apk` 即可下载（公开仓库无需登录，也不用解压）。

**从 v1.2 升级：直接覆盖安装**，数据不会丢（签名没变，应用内部包名 `com.riheng.app` 也没变）。
只有从 v1.1 或更早升级时需要先卸载一次（当时签名不同）。

## v1.6 更新
- **图标库**：内置图标从 18 个增加到 **358 个**（来自开源的 [Lucide](https://lucide.dev)，ISC 许可，许可全文随安装包分发，见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)），分成 常用 / 运动 / 健康 / 饮食 / 学习 / 生活 / 心情 / 爱好 / 自然 / 出行 / 财务 / 数码 12 类，每个都有中文名，支持**搜索**（中文名、英文名、关键词，如「跑步」「水」「book」）。
- **自定义图标二选一**：「图标库」里挑一个，或「相册图片」从手机相册选一张（自动裁成方形）。
- **二级「编辑习惯」页**：点一下任何习惯卡片进入，可以改名称、图标、重复频率；新增习惯也用同一页。有未保存的修改时，点返回/系统返回键会先问一句。
- **删除键移入编辑页**（页面最下方，仍需二次确认），列表卡片上不再放删除图标，也就不会误点。
- **自定义排序**：按住卡片左侧的手柄上下拖动即可，顺序会保存，小组件里的顺序也跟着变。在「待完成 / 已完成」筛选下排序时，看不见的习惯位置保持不变。
- **周条选中态变小**：选中的日期只让数字圆圈变蓝（原来整根竖条都变蓝，显得太大）；日期下的小点表示这天有打卡记录。
- 小组件：图标库里的图标在小组件里显示为最接近的 emoji（小组件只能显示文字）。
- 升级：直接覆盖安装，原有习惯、打卡记录和旧图标都保留。

## v1.5 更新
- **主色改为蓝色**，与图标一致：按钮、进度环、打卡按钮、选中日期、统计图、小组件（含深色模式）都换成蓝色，蓝底上一律白字；页面底色改为偏冷的浅灰白。
- **字号整体放大**：原来为了塞进一屏，各版本把字越压越小（说明文字 8–10px，习惯名只有 13px）。现在按层级统一：标题 20–34px、习惯名与列表标题 15–16px、说明 13px、标签 12px，最小不低于 11px；按钮、导航、日历格子、删除键的点按区域也一并放大。
- 其他：进度环放大、「今日完成」不再压在环上；提示条不再盖住底部导航；「＋ 新习惯」按钮不再出现两个加号；全部完成时的标题改短，小屏不再出现单字换行；统计图标题与柱子之间留出间距。
- 小组件文字略微放大（11sp → 12sp，12sp → 13sp）。

## v1.4 更新
- **新图标**：蓝色底 + 白色圆圈里一个对勾，简洁；自适应图标，支持 Android 13+ 主题色图标，启动页图标底色同为蓝色。
- **输入法弹出掉帧**：原因是每一帧都在改整个页面的样式变量，浏览器要整页重算样式。现在原生只在键盘动画开始时告诉页面「目标高度 + 时长」，由浏览器合成线程完成动画；「新习惯」背后不再做全屏模糊。实测样式计算约 60 ms → 约 3 ms（Chromium 模拟，未在真机实测，详见 [BUG_AUDIT.md](BUG_AUDIT.md)）。
- **修复**：习惯名字很长时页面会被撑宽、整体缩小；点周条上的未来日期会选中无记录的日子；没有当天计划时主按钮提示不准确。

## v1.3 更新
- **新图标**（v1.4 已更换）：深橄榄黑底 + 字母 P，自适应图标，并支持 Android 13+ 的主题色图标。
- **改名 Persist**：桌面名称、小组件、页面标题与关于页、备份文件名（`Persist-backup-日期.json`）。
  旧版（日恒）导出的备份仍可导入。
- **启动过渡**：系统启动页（浅色底 + 图标）一直保留到页面准备好，然后淡出，页面内容和习惯卡片依次上浮、进度环从 0 填充；
  弹窗的开合也加了过渡。
- **输入法**：
  - 不再自动弹出键盘（原来打开「新习惯」时在滑入动画中途弹出，显得生硬）。
  - 点输入框后，弹窗跟着键盘平滑上移，不再被遮挡（v1.4 改为一次性下发目标高度，见上）。
  - 「新习惯」面板改为标题和底部按钮固定、中间内容滚动，键盘弹出时「取消 / 保存」始终可见。
- **删除确认框**：改为居中的窄卡片（最宽 340px，左右至少 24px 留白），原来在手机上几乎撑满左右。
- 青柠底色上的文字改为深色（「保存习惯」「每天」等原来是白字/浅绿字，几乎看不清）。

## v1.2 更新（保留）
备份导出/导入走系统文件选择器、固定签名、小组件按高度精确显示并支持深色、返回键分层、跨天自动刷新等，详见 [BUG_AUDIT.md](BUG_AUDIT.md)。

## 构建 APK
- **GitHub Actions**：见上，自动构建并发布 Release；也可在 Actions 页手动运行 workflow。
- **Android Studio**：打开项目根目录，安装 Android SDK Platform 35 和 JDK 17，Build > Build APK(s)，产物在 `app/build/outputs/apk/debug/app-debug.apk`。

> `app/riheng.jks` 是个人自用的固定签名文件，密码写在 `app/build.gradle.kts` 里，用于保证覆盖安装。
> 它不适合用于上架应用商店；仓库公开时，也不要用它签名任何需要保密的应用。

## 测试桌面小组件
安装后长按桌面空白处 → 小组件 → 搜索「Persist」→ 添加「Persist 打卡小组件」。不同桌面的操作名称可能略有差异。

## 数据与限制
- 习惯和打卡记录保存在应用内（WebView 本地存储 + 原生 SharedPreferences 副本，后者供小组件使用）。**卸载应用会清除数据**，请定期在设置里导出备份。
- 自定义图片图标在应用内可用；小组件里显示为 🌿，图标库图标显示对应 Emoji。
- 当前版本不含云同步、账号系统或通知提醒；应用只有浅色主题。
