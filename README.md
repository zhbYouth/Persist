# Persist

一个轻量的 Android 习惯打卡应用（原名「日恒」）：主界面是 WebView 网页（`app/src/main/assets/index.html`），外加原生桌面小组件，数据在应用内本地保存，不需要账号和联网。

## 功能
- **今日**：当天计划列表，点圆圈打卡，未完成在上、已完成沉到底部；按住手柄拖动排序；点「已完成」查看今天完成了什么。
- **习惯**：自定义名称、图标库图标、重复日（每天 / 每周几 / 自定义）。
- **统计**：周 / 月 / 年三档，完成率、全部完成的天数与连续天数、每日完成率图表；点任一习惯进入详情（连续、日历、星期分布）。
- **日历**：翻看任意一天的完成情况。
- **桌面小组件**：在桌面直接看今日计划并打卡。
- **每日提醒**：设置里选一个时间，还有没完成的习惯才会提醒。
- **备份**：设置里可导出 / 导入数据。

## 下载安装
打开仓库的 **Releases** 页，下载最新的 `Persist-x.y.z.apk` 安装即可。升级直接覆盖安装，数据不会丢（包名 `com.riheng.app` 与签名保持不变；只有从 v1.1 或更早升级时需要先卸载一次）。
每次推送到 `main`，GitHub Actions 会自动构建并发布新的 Release。

## 添加小组件
长按桌面空白处 → 小组件 → 搜索「Persist」→ 添加「Persist 打卡小组件」（不同桌面的叫法可能略有差异）。

## 自行构建
用 Android Studio 打开项目根目录（Android SDK Platform 35、JDK 17），Build > Build APK(s)；或直接用 GitHub Actions。
> `app/riheng.jks` 是个人自用的固定签名文件，密码写在 `app/build.gradle.kts` 里，仅用于保证覆盖安装，不适合上架，也不要用它签名需要保密的应用。

## 数据与限制
- 数据保存在应用内（WebView 本地存储 + 供小组件读取的原生副本）。**卸载应用会清除数据**，请定期导出备份。
- 小组件里自定义图片图标显示为 🌿，图标库图标显示对应 Emoji。
- 暂无云同步和账号系统；只有浅色主题。
